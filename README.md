## Project Overview
Spring Boot REST API backing a Waste Management System with PostgreSQL, supporting entity relationships, custom JPQL queries, state machine scheduling, disposal records, and system analytics.

🛠️ Tech Stack
Springboot – java backend framework
PostgreSQL – Powerful, open-source relational database.

⚙️ Getting Started
Follow the steps below to set up the project locally.

1. Clone the repository
git clone https://github.com/beni-jnx/waste-management-system-backend.git 
2. Install dependencies
 jpa
 postgres drive
3. Start the server
 mvn spring-boot:run
